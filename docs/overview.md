# 概要

> [!NOTE]
> app-scout の狙い、守ること、解決したい不満、最初のリリースの機能が分かる。
> 作る順番は [roadmap](roadmap.md) にある。

競合アプリのレビューから不満を集め、新しいアプリの企画書の下書きを作るエージェントである。個人でアプリを作る人の「題材を決めるまでの調べ物が重い」という不満を解く。

| 項目 | 内容 |
| --- | --- |
| 名前 | app-scout |
| 形 | 手元で動かす Web API と CLI |
| 作る人 | 1 人。自分のアプリの企画に使う |
| 期間 | 4 か月、週 30 時間 |

## 📏 守ること

作る時に、次の決まりを守る。

> [!IMPORTANT]
> - レビューは App Store の RSS から取るのを主にし、足りない分だけ Web 検索で補う
> - レビューの投稿者の名前は保存しない。本文・星・日付だけを持つ
> - 費用がかかる API は、1 回の実行ごとに上限の額を決めて止める

## 😣 解決したい不満

企画を始める時に、手で調べると重い所と、それに応える機能である。重さは 🔴 高、🟠 中、🟡 低で書く。

| 不満 | 重さ | 対応する機能 |
| --- | --- | --- |
| 競合のレビューを 1 件ずつ読むのに時間がかかる | 🔴 高 | レビューを集めて、不満を分類する |
| 似た不満が言い方を変えて何度も出て、数をつかめない | 🔴 高 | 似た不満をまとめて、件数で並べる |
| レビューの少ないアプリは、ストアだけでは不満が足りない | 🟠 中 | Web 検索で補う |
| 不満から最初のリリースの機能を決めるまでが重い | 🟠 中 | overview と roadmap の下書きを書く |

## ✨ 最初のリリースの機能

モデルは Claude API の Sonnet 5.5 と Haiku 5.5 を使い、埋め込みは手元のモデルで作る。

| 機能 | 中身 |
| --- | --- |
| アプリを探す | 題材の言葉から、日本の App Store の競合アプリを探す |
| レビューを集める | RSS から、新しい順に 500 件までを取って SQLite に保存する |
| Web 検索で補う | レビューが足りないアプリは、Sonnet 5.5 の Web 検索で不満を集める |
| 不満を分類する | Haiku 5.5 で、レビューを不満の種類と重さに分ける |
| 似た不満をまとめる | 手元の埋め込みと sqlite-vec で、似た不満を 1 つにまとめる |
| 下書きを書く | Sonnet 5.5 で、overview と roadmap の下書きを書く |
| 下書きを採点する | Haiku 5.5 で、下書きが不満に応えているかを採点する |
